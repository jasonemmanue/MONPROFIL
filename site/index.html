02 / Méthode

Une journée pour livrer une application qui fonctionne

En hackathon, j'applique ce que je fais déjà en production : peu d'écrans, un parcours complet de bout en bout et une démo en ligne.

  1. 01

    Cadrer

    Un utilisateur cible, un parcours prioritaire et une maquette validée avec l'équipe avant la première ligne de code.

    Appuyé sur : diagnostic digital de 4 TPE

  2. 02

    Construire

    Interface Flutter ou Next.js, API FastAPI ou Firebase selon le délai. Le modèle de données est posé dès la première heure.

    Appuyé sur : AgriSmart CI, Prepaxia

  3. 03

    Connecter

    Authentification, notifications et paiement Mobile Money quand le cas d'usage le demande.

    Appuyé sur : GeniusPay, Orange, MTN, Wave, carte

  4. 04

    Livrer

    Application en ligne avec un lien public, démo testée sur téléphone et indicateurs clés prêts pour le jury.

    Appuyé sur : tableaux de bord et rapports du PAA
